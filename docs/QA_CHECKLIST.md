# Чек-лист приёмки hwforai · maxv

Выполняйте на отдельных тестовых базах с Mailpit. Для закрытого контура установите `EXCHANGE_DEMO_FEATURES=true`. Для регрессии открытой регистрации оставьте настройки по умолчанию. Для проверок HTTPS используйте отдельный контур рабочего режима с тестовым SMTP и временными секретами.

Зафиксируйте коммит, режим, браузер, ширину, роль и тестовые данные. Для каждого сбоя сохраните шаги, ожидаемый и фактический результат. Перед публикацией повторите исправленные сценарии и соседние операции с тем же объектом на проверяемом коммите.

## Приоритеты

| Приоритет | Что задерживает выпуск |
| --- | --- |
| P0 | Доступ без полномочий, утечка контактных данных или документов, неверные сведения об оплате или публикации, потеря данных при обновлении |
| P1 | Невозможность пройти основной путь роли, перекрытие фильтров и выдачи, нарушение клавиатурной навигации, неверный смысл статуса |
| P2 | Неточная формулировка, повторяющееся действие, потеря контекста при переходе или локальная ошибка выравнивания |

## Сборка и выпуск

- `npm run check` и `npm run build` завершаются с кодом 0. На старом и обновлённом стендах сохранились активные записи, существующие ограничения и история.
- `tests/catalog_ui.py` проверяет заголовок и поиск на главной, отсутствие декоративного изображения, гостевой доступ, карточку и возврат в отфильтрованную выдачу. Для визуального просмотра можно задать каталог скриншотов через `HWFORAI_SCREENSHOTS`.
- `tests/catalog_staff_ux_e2e.py` проверяет границы элементов внутри панели фильтров, положение панели относительно выдачи и разграничение ролей. Сборка браузерного клиента проверяется при включённых функциях закрытой биржи.
- `tests/contextual_moderation_e2e.py` проверяет реальные операции над карточкой и профилем, доступ к справочнику категорий, сохранение контекста и управление страницами и языками.
- `tests/exchange_admin_e2e.py` проверяет диалоги над прокрученным справочником моделей на настольном экране, планшете и телефоне, журнал правок и права на действия со справочником и источниками.
- `tests/exchange_dialogs_e2e.py` проверяет контекстные диалоги приглашений, записей раскрытия, полномочий и ценовых ориентиров на настольном и мобильном экранах.
- Полная матрица в `server/test/` и `tests/` включает сценарии открытой и закрытой регистрации, защиту API модерации, поиск, изображения, чаты, приглашения, представительство, совпадения, проверки и контроль актуальности. Проверяйте число пропусков в TAP и запускайте нужные сценарии на отдельных стендах.
- В рабочем режиме проверьте HTTPS, SMTP STARTTLS, выдачу защищённого cookie, роли и получение кода. Локальное обновление через `scripts/update-maxv.sh` должно сохранить том PostgreSQL и работать только с веткой `maxv`.
