# Работа с репозиторием hwforai

- Обновляйте единый актуальный [README.md](README.md) вместе с функциональностью, API и командами запуска. Поддерживайте цельное руководство для текущего состояния проекта. Старые адреса документации могут содержать короткие ссылки на нужные разделы README.
- При изменении схемы добавляйте новую миграцию. Проверяйте применение на чистой базе и на копии базы предыдущей опубликованной версии. Сохраняйте контрольные суммы уже опубликованных миграций.
- Перед публикацией проверьте сборку и регрессии, затронутые изменением. При изменении пользовательских сценариев проверьте соответствующие роли на мобильном и настольном размерах. Фикстуры, секреты и результаты локальных прогонов остаются вне коммита.
- При запросе на публикацию сверяйте удалённую ветку `main` и после отправки проверяйте, что именно протестированный коммит доступен в GitHub.
