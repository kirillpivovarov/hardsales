# hwforai

Русскоязычная площадка объявлений о покупке и продаже серверного оборудования для задач ИИ. Покупатели публикуют запросы, продавцы размещают предложения. Зарегистрированные участники находят друг друга по характеристикам оборудования и условиям поставки, затем начинают переговоры в чате.

## Запуск на своём компьютере

Запустите Docker Desktop или Docker Engine с плагином Compose. В своём терминале скачайте репозиторий и поднимите демостенд.

```sh
git clone https://github.com/kirillpivovarov/hardsales.git
cd hardsales
docker compose up --build -d --wait
```

Если Git не установлен, скачайте архив через **Code → Download ZIP** на GitHub и выполните последнюю команду из распакованной папки, где находится `compose.yaml`. Дождитесь состояния `healthy` у сервиса `app`.

Откройте эти страницы в Chrome на компьютере, где запустили Docker.

- [Площадка hwforai](http://127.0.0.1:3000)
- [Письма с одноразовыми кодами в Mailpit](http://127.0.0.1:8025)

Порты задаются переменными `APP_PORT` и `MAILPIT_UI_PORT`. Настройки PostgreSQL и локального SMTP для демостенда находятся в `compose.yaml`.

## Обновление запущенного Docker Desktop

Оставьте Docker Desktop запущенным и откройте терминал в папке с текущим `compose.yaml`. Сделайте резервную копию PostgreSQL. [Команды резервного копирования](docs/operations.md#обновление-уже-запущенного-демостенда)

- **Если ставили через Git**, проверьте состояние файлов командой `git status --short --branch`. На чистой ветке `main` выполните `git pull --ff-only origin main`.
- **Если ставили из ZIP**, скачайте свежий архив через **Code → Download ZIP**. Распакуйте его в новую папку. Перенесите свои настройки `.env` и используйте терминал в новой папке.

При стандартном запуске имя проекта Compose — `hwforai`. Из папки с обновлённым `compose.yaml` выполните команды.

```sh
docker compose -p hwforai up --build -d --wait app
docker compose -p hwforai ps
```

Если при первом запуске вы задали другое имя проекта, подставьте его вместо `hwforai`. С тем же именем проекта Compose подключит существующий том PostgreSQL. Миграции применятся автоматически. После статуса `healthy` обновите страницу в Chrome по прежнему адресу.

## Проверка вручную

| Роль | Логин | Пароль |
| --- | --- | --- |
| Продавец | `test1` | `test1` |
| Покупатель | `test2` | `test2` |
| Администратор | `admin` | `admin` |

1. Откройте каталог как гость. Категории и поиск доступны, а для просмотра объявлений потребуется вход.
2. Войдите как продавец `test1` и нажмите **«Разместить»**. В форме предложения выберите **«Из любой страны»** в поле **«Страна отгрузки»** и нажмите **«Добавить фото»**. Можно прикрепить до 10 файлов JPEG, PNG или WebP размером до 8 МиБ каждый. Сохраните предложение и проверьте порядок фотографий, обложку и водяной знак в карточке.
3. В окне инкогнито войдите как покупатель `test2`. Найдите предложение в каталоге, откройте галерею и нажмите **«Написать»**. В первом окне ответьте продавцом в разделе **«Чаты»**. Проверьте, как раскрытие Telegram запрашивается одной стороной и подтверждается другой.
4. Войдите как `admin` и смените начальные реквизиты в настройках. В админке можно изменить категории, объявления и их изображения, профили, страницы и языки.
5. Для проверки регистрации используйте вымышленный адрес вида `tester@example.test`. Возьмите код подтверждения из Mailpit. Адреса двух готовых аккаунтов уже подтверждены.

Для диагностики посмотрите журнал приложения. Второй командой остановите демостенд после проверки.

```sh
docker compose logs --tail 100 app
docker compose down
```

После остановки данные сохраняются в томе PostgreSQL. Демостенд с тестовыми паролями доступен на компьютере, где работает Docker.

## Рабочий запуск

GitHub хранит исходный код. Для доступа к сайту из интернета запустите образ из `Dockerfile` на хостинге, подключите PostgreSQL и SMTP, настройте домен и HTTPS. Список переменных и порядок запуска приведены в [инструкции по эксплуатации](docs/operations.md).
